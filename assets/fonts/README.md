# Bundled fonts

Only fonts under the SIL Open Font License (OFL) go here, each with its `OFL.txt`.
None are bundled yet; candidates are Comic Neue, Bangers, Patrick Hand and Cinzel Decorative.

Fonts whose licences forbid redistribution (Blambot's Anime Ace, Badaboom and Mouth Breather;
Microsoft's Impact and Comic Sans; CC Wild Words) are never committed. AsagiType loads them
from the fonts folder you set in Tools > Settings.
